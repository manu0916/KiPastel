# Ki Pastel — site demonstrativo

Protótipo front-end responsivo para a Pastelaria Ki Pastel. O catálogo, os sabores, os valores e os horários são demonstrativos e podem ser ajustados antes da publicação oficial.

## Desenvolvimento

```bash
npm run dev
```

## Build

```bash
npm run build
```

O conteúdo final é gerado em `dist/`.

## Cloudflare Pages

- Build command: `npm run build`
- Build output directory: `dist`
- Node.js: `20` ou superior

O site é totalmente estático e não precisa de variáveis de ambiente.
